# Framezoo Desktop Releases

Official distribution repository for **[Framezoo](https://framezoo.top)** — a fast desktop video streaming media player for macOS and Windows with rich movie metadata, unlimited subtitle synchronization, multi-source subtitle providers, and an open HTTP/JSON addon ecosystem.

- **macOS 12+** — Apple Silicon (`arm64` `.dmg`) & Intel (`x64` `.dmg`)
- **Windows 10 / 11** — `x64` (`.exe`) & `ARM64` (`.exe`)
